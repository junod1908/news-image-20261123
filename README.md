Sum up 23 November 2026's world news in one image — a one-page broadsheet, "The World in One Day": a masthead naming the day, a date-check strip, a dot world map with a red marker at every story's place, and 36 numbered story cards across regions and fields (Americas, Europe, Middle East & Africa, Asia-Pacific, technology & markets). Every story was date-audited to Monday 23 November 2026 — weekend events recycled by Monday digests were left out on purpose, and the poster's date line says so on its face. The program draws the whole page itself with the Python standard library only (no network): every word is set in type by the program from the bitmap fonts in `assets/font.bin`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
